# Git remotes

This project uses GitHub as its only remote. Preserve the existing host,
visibility, and branch settings.

| Remote | URL |
| --- | --- |
| `origin` | `git@github.com:jubishop/jubishop.github.io.git` |

A fresh clone needs no further remote setup: `origin` fetches from and pushes
to GitHub.
